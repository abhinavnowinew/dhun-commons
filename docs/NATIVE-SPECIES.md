# Native and regional species photographs

The Field map and produce list use real species photographs instead of category
illustrations. Every file in `qml/assets/produce/` is a downscaled,
recompressed copy of the Wikimedia Commons file listed below; the only edit is
resizing and JPEG recompression. Each image remains under its own licence, as
listed. The application source code is not relicensed by these image licences.

These are **species reference photographs**, not photographs of Dhun.life's own
fields, animals or harvest. The 11-card "Native & foraged" ribbon uses the same
files for khejri, sangri, ker, kumatiya, gunda, amla, ber, moringa, Rathi cow,
Sirohi goat and desi poultry. All inventory, yields and orders remain labelled
rehearsal data in the app.

## Native-species notes used in the app

- **Khejri** (*Prosopis cineraria*) is Rajasthan's state tree and the source of
  sangri pods. The app treats the tree and the foraged pod as separate reference
  cards.
- **Ker** (*Capparis decidua*), **kumatiya** (*Senegalia senegal*) and **gunda**
  (*Cordia dichotoma*) are dryland trees/shrubs whose buds, gum, pods or fruit are
  traditionally foraged.
- **Amla** and **ber** are native fruit species; the amla photograph was taken in
  Pushkar, Rajasthan.
- **Rathi cattle** and **Sirohi goats** are Rajasthan breeds. The desi poultry
  photograph is a general country-chicken reference, not a Dhun flock.
- Spinach, wheat, tomato, guava, lemon and some vegetables are cultivated or
  introduced species in Rajasthan; they are included because they are part of the
  field's working crop plan, not because they are botanically native.

## Replacing these with Dhun's own photographs

Drop a new JPEG at the same path (for example
`qml/assets/produce/khejri.jpg`), keep the filename, and update this table. The
Field map reads the file name from `producePhotos` and `nativeSpecies` in
`qml/data.js`.
